# section-050 / capstone: Section Capstone — New App Server Onboarding

QEMU VM for the LFCS course — the Section 050 capstone. Connects every skill from this section into one onboarding pass on a freshly provisioned application server: trust and pin a vendor repository, recover a package stuck mid-install, install a toolchain and bulk-hold a package family, and research a package to answer a specific onboarding question.

astrona run --git git@github.com:astrona-io/ATS002.git -c sections/section-050/capstone/labs/lab-01
